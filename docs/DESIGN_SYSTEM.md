# Design System

The Design System defines the visual and ergonomic standards for Evidence Vault. It establishes how information and actions are positioned, grouped, and prioritized across the product.

This document aligns with the Product Constitution ([`PRODUCT_PRINCIPLES.md`](../PRODUCT_PRINCIPLES.md)) and the UX Architecture ([`UX_ARCHITECTURE.md`](UX_ARCHITECTURE.md)). Where product principles define *why* and UX architecture defines *how users experience* incident reconstruction, this document defines *how the interface is physically organized* for clarity and reachability.

For the full visual system (colour, typography, spacing, components), see [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md) at the repository root.

---

## Reachability Principles

Primary actions belong within the natural thumb zone.

Informational content occupies the upper portion of the interface.

Primary capture controls should remain visually grouped together and consistently positioned throughout the application.

Users should never search the screen for the next capture action.

Consistency of action placement is preferred over perfectly symmetrical layouts.

---

## Design Principle

**Information lives where users look.**

**Actions live where users reach.**

---

*This document is the canonical design standard for Evidence Vault. All screens, components, and layouts must conform to these reachability and placement principles.*

For colour, typography, cards, **Status Indicators**, and the full visual component catalogue, see the root [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md).
